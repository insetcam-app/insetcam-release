# InsetCam releases

Signed and Apple-notarized macOS builds of **InsetCam** — a floating camera
picture-in-picture overlay for screen recording and live streaming.

Downloads live on the [Releases](../../releases) page. The source repository stays
private. InsetCam is an independent MIT-licensed fork of
[SameShot](https://github.com/JackAIStudio/SameShot) by JackAIStudio.

- Website: https://insetcam-landing.pages.dev
- Requirements: macOS 13 or later, Apple Silicon
